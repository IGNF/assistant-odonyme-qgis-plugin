# Assistant odonyme

This plugin assists with entering the street names (odonyms) associated with road segments in the BD TOPO database.

## Pré-requis

Mandatory : The "plugin\_maitre" must be installed.
Link to the plugin maître : [maitre-qgis-plugin sur GitHub](https://github.com/IGNF/maitre-qgis-plugin)

## Fonctionnalités

French : 
* Saisir ou modifier les odonymes (Noms collaboratifs gauche et droite) d’un ou plusieurs tronçons.
* Saisir ou modifier les alias gauches et droites d’un ou plusieurs tronçons.
* Visualiser les Nom BAN (gauche et droite)
* De sélectionner tous les tronçons de même odonyme d’une commune sélectionnée.

English :
* Enter or edit the odonyms (collaborative street names on the left and right sides) for one or more road segments.
* Enter or edit the left and right aliases for one or more road segments.
* View BAN names (left and right sides)
* Select all road segments with the same odonym within a selected municipality.
